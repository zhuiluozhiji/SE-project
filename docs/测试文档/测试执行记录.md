## 4. 爬虫真实联网测试记录

### 4.1 轻量连通性验证

执行方式：在 backend 容器中直接调用爬虫模块请求列表页。

目标地址：

```text
http://cspo.zju.edu.cn/27181/list.htm
```

实际结果：

| 项目 | 结果 |
| --- | --- |
| HTML 长度 | 约 30599 字符 |
| 第一页解析条目 | 15 条 |
| 示例活动 | `【致远计划】关于选拔优秀研究生参加“致远”计划...` |

结论：当前环境能够真实访问 CS ZJU 学生活动列表页，并解析列表条目。

### 4.2 完整爬虫运行

执行接口：

```bash
curl --noproxy '*' --max-time 240 -sS \
  -X POST http://127.0.0.1:8000/api/v1/admin/crawler/run \
  -H 'Content-Type: application/json' \
  -d '{"source":"cs_zju"}'
```

实际返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "source": "cs_zju",
    "status": "success",
    "fetched": 215,
    "created": 6,
    "skipped": 0,
    "filtered": 98,
    "year_filtered": 111
  }
}
```

爬虫记录接口：

```bash
curl --noproxy '*' -sS 'http://127.0.0.1:8000/api/v1/admin/crawler/records'
```

实际结果摘要：

| source | status | fetched_count | success_count | error_msg |
| --- | --- | --- | --- | --- |
| `cs_zju` | `success` | 215 | 6 | `filtered=98, year_skipped=111, dup_skipped=0` |

结论：爬虫在当前网络环境下可真实访问官网、抓取详情、过滤内容并写入数据库。
